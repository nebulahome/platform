# @nebulahome/package-sdk

What a NebulaHome package is written with: its declaration (`nebula.config.ts`), its server, its
page, cards and entity views, and the Vite plugin and command that build it into a release.

The reference is `PACKAGES_DOCS.md` in the NebulaHome documentation; a package starts from
[nebula-home/pkg-template](https://github.com/nebula-home/pkg-template).
